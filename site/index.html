    ❓ How the recipient opens it

    Windows
    1. Install 7-Zip (free, 7-zip.org), or use WinRAR or WinZip.
    2. Right-click the .7z file → 7-Zip → Extract Here (or open it in the app).
    3. Enter the password exactly as received — it is case-sensitive.

    Windows' built-in archive support may not open encrypted .7z files; use one of the apps above.

    Mac
    1. Install Keka or The Unarchiver (free, Mac App Store). Archive Utility cannot open .7z.
    2. Double-click the .7z file and enter the password when prompted.
    Phone / Linux
    • Android: ZArchiver. iPhone/iPad: an app that supports encrypted 7z (e.g. iZip).
    • Linux: 7z x Secure_Documents.7z (p7zip / 7-Zip).
